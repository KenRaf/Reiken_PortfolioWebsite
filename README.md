# Kristoffer Raflores - Personal Portfolio

Welcome to the source code for my personal portfolio website! This repository showcases my projects, professional certificates, skills, resume, and background details as an aspiring tech professional / intern.

---

## 🚀 Features

- **Interactive UI & Motion:** Built with custom vanilla JavaScript modules and CSS animations (`motion.css`, `alt.css`) for a smooth, dynamic user experience.
- **Certificate Showcase:** Displays professional certifications including Java, Python, and PMI Project Management Ready.
- **Embedded Resume:** Easy access to my professional intern resume (`Kristoffer_Raflores_Intern_Resume.pdf`).
- **Ambient Audio:** Integrated background music player featuring royalty-free tracks.
- **Fully Responsive:** Designed to look great across mobile, tablet, and desktop devices.

---

## 📂 Project Structure

```text
Raflores_Portfolio/
│
├── index.html                  # Main entry point for the portfolio
├── css/                        # Stylesheets
│   ├── styles.css              # Core styling
│   ├── motion.css              # Animation & transition styles
│   └── alt.css                 # Alternative theme / secondary styles
│
├── js/                         # JavaScript application logic
│   ├── app.js                  # Main script controller
│   ├── content.js              # Dynamic content loader
│   ├── intro.js                # Intro animations / greetings
│   ├── motion.js               # UI motion and interactive effects
│   ├── settings.js             # User settings / preferences handler
│   └── alt.js                  # Secondary script logic
│
└── assets/                     # Media, documents, and resources
    ├── favicon.svg             # Website icon
    ├── Kristoffer_Raflores_Intern_Resume.pdf
    ├── certificates/           # PDF documents and image badges (Java, Python, PMI)
    ├── music/                  # Background audio tracks
    ├── photos/                 # Personal and project imagery
    └── projects/               # Showcase project assets
```

## 💻 Running Locally

To run this project on your local machine:

1. Clone or download this repository.
2. Open the folder in your code editor (e.g., [VS Code](https://code.visualstudio.com/)).
3. Use a local server extension (like **Live Server** in VS Code) to open `index.html`, or open `index.html` directly in your web browser.
